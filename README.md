# eri-cli

Personal portfolio for Eric Li, focused on homelab operations, networking, and site reliability.

[View the live site](https://natchannnn.github.io/eri-cli/)

The site uses HTML, CSS, and plain JavaScript. Three.js renders the desktop terrain; canvas and SVG provide fallbacks for smaller or less capable devices.

## Run locally

Serve the root directory with any local HTTP server:

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

Then open `http://localhost:8000` in your browser.

## Build and verify

The site uses npm scripts for asset bundling, static site generation, and integrity checks:

```bash
# Run the complete build (CSS bundling + blog generation)
npm run build

# Bundle CSS modules into assets/css/style.css
npm run build:css

# Compile Markdown articles into static blog pages
npm run build:blog

# Run comprehensive test suite
npm test
```

> **Note**: Do not edit `assets/css/style.css` or files under `blog/` directly. They are generated build artifacts. Edit the source modules in `assets/css/` or Markdown files in `content/blog/`, then rebuild.

`npm test` checks:
- Presence of required core documents.
- CSS bundle freshness (verifies `style.css` matches source modules).
- Tablet viewport geometry (verifies grid minimums remain under 900px).
- Internal link integrity across all HTML pages.
- Syntax validation for all first-party JavaScript files.
- Blog route completeness.

## Updating projects

1. **Full list (`projects.html`)**: Project entries live in `<ol class="project-ledger">`. To add an entry, append an `<li class="project-entry">` containing the title, description, and facts.
2. **Homepage highlights (`index.html`)**: The top 3 projects are defined in the `#projects` section and configured in `assets/js/home.js` (`projectData` array).

## Publishing a blog post

Source articles are stored in `content/blog/` as Markdown files named `YYYY-MM-DD-slug.md`.

Each post requires YAML frontmatter:

```markdown
---
title: "Setting Up Proxmox VE Clustering"
date: 2026-10-15
category: Homelab
summary: "Corosync quorum configuration, shared ZFS storage, and migration testing."
---

Article body in standard Markdown.
```

To compile posts and update `blog/index.html`:

```bash
npm run build:blog
```

The script parses Markdown, calculates reading time, wires previous/next post links, and regenerates static HTML routes into `blog/<slug>/index.html`.

## Generated files

The following files are generated by build scripts and should not be edited by hand:

- `assets/css/style.css`: Bundled from modular CSS sources via `npm run build:css`.
- `blog/**/index.html`: Static blog post routes rendered from `content/blog/` via `npm run build:blog`.
- `blog/index.html`: Blog archive index rendered from `templates/blog-index.html`.

These paths are marked with `linguist-generated=true` in `.gitattributes` so GitHub diffs and language statistics exclude them automatically.
